7 silent PyTorch failure patterns (checklist, 2 pages)

  1. NaN brutal : une seule operation instable contamine tout. Check : detect_anomaly sur run reduit.
  2. LR trop eleve + activation saturee : escalier des les premieres etapes. Check : LR/10 sur 50 etapes.
  3. Gradients evanouissants : couches profondes figees. Check : normes par couche a l'etape 100.
  4. ReLU morts en masse : >50 % a zero. Check : histogramme des activations.
  5. Oubli train()/eval() : ecart fantome. Check : meme batch dans les 2 modes.
  6. Seed et non-determinisme : 2 runs, 2 destins. Check : seeds fixees + versions notees.
  7. Donnees corrompues en silence : labels decales, fuite train/test. Check : visualiser 1 batch reel.
